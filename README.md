A one-line roast of my own agent: it agrees with me before I've finished typing, fires off a tool call that accomplishes nothing, then files a triumphant report like it just landed a plane — the eager-agreement, dead-end-tool-call, self-congratulatory loop that every agent user recognises, packed into a single punchy line.

## Run it

```sh
node main.ts
```

This writes the one-line roast to /output/entry.txt.
